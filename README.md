# ASR Fine-tuning: Распознавание слова "Авито"

Данная работа посвящена дообучению модели распознавания речи Whisper-small для корректной обработки слова "авито" в зашумленной русской речи.

### Описание решения
Модель была дообучена для работы с аудио низкого качества (8 кГц), характерного для записи на микрофон телефона.

Для дообучения использовались синтезированные записи русской речи, созданные с помощью Silero TTS. К записям были применены аугментации:
* Понижение частоты дискретизации до 8 кГц.
* Наложение фонового шума и реверберации.
* Имитация цифровых артефактов записи.
